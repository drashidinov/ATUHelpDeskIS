# ATU HelpDesk IS

Система техподдержки компьютерных классов АТУ:
1. Расписание занятий по аудитории (свободна / идёт занятие).
2. Вызов специалиста техподдержки из класса, с отображением на табло офиса.

## Структура

- `app/index.html` — рабочий прототип (терминал класса + табло ТП) на статичных
  данных из расписания 1 академического периода 2026-2027 уч. года. Вызовы
  специалиста хранятся через `window.storage` (Claude Artifacts persistent
  storage) — работает как живая демо-версия при открытии в Claude.
- `data/rooms_meta.json` — список 44 аудиторий-компьютерных классов, закреплённых
  за техподдержкой (корпуса 2Б, 2C, ГУК), с адресами корпусов.
- `data/schedule_final.json` — 332 записи занятий, извлечённые из расписания для
  этих аудиторий (день недели, время, группа, текст занятия).
- `data/rooms_extracted_all_mentions.csv` — все уникальные варианты обозначения
  аудиторий, найденные во всех расписаниях (для справки/будущей сверки).
- `scripts/rooms.py` — список целевых аудиторий + нормализация/распознавание
  номера аудитории в свободном тексте расписания.
- `scripts/parse_schedules.py` — парсер: читает .xlsx расписания (структура —
  один лист на группу, дни/время по строкам, подгруппы по столбцам), находит
  ячейки с упоминанием целевых аудиторий и выгружает в `schedule_final.json`.

## Следующие шаги для продакшна

- Backend (API + БД) вместо статичного JSON — чтобы расписание обновлялось
  автоматически при поступлении новых файлов и не требовало пересборки
  прототипа.
- Реальный WebSocket/push для табло вместо поллинга.
- Авторизация специалистов на табло (кто принял вызов).
- Интеграция физической кнопки (ESP32) — дергает тот же API-эндпоинт, что и
  веб-кнопка.
